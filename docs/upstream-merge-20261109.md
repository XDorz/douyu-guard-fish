# v1.4.0：合并上游 v1.0.17

合并来源：`qlingzzmm01/douyu-guard-fish` 的 `0b61cbd`（2026-11-02）和
`ae33f15`（2026-11-05）。共同祖先为 `35c7c85`；本分支原版本为 v1.3.2 / `ae26f0b`。
使用保留双方历史的 merge commit，方便继续合并后续上游提交。

## 冲突取舍

| 上游变化 | 本分支处理及原因 |
| --- | --- |
| 优先 Patchright、源码回退 Playwright | 合入；发行包固定 Patchright 1.64.4。适配旧 `isolatedContext` 与新 `isolated_context` 参数。错误不通过重新执行脚本来兜底，避免重复点击。 |
| 主世界注入 + localStorage 配置/状态代理 | 使用已验证的主世界直接执行接口；保留现有动态加载/撤销，不增加每 250/400ms 的 localStorage 读写，也避免暂停后的配置重装。 |
| 网络回调缓存 | 合入；合并现有每日次数、阶段耗时与 Debug 回调。清除页面导航前的旧缓存，接受成功响应，保留真实 0 次/0 HP。移除 fetch/XHR 包装。 |
| DOM 查找 React fiber 兜底 | 合入，仅在原有入口不能定位引擎时扫描。引擎自身的关卡标识仍优先，网络关卡作为计数兜底。 |
| 曲线鼠标、滚动到挑战按钮 | 合入；增加付费文本保护、点击前遮挡检查和 API 暂停检查。跳过战斗期间无功能的鼠标微动，减少事件开销。 |
| 随机动作等待、偶发较长场间等待 | 合入；监控仍每 0.5 秒轮询，宽限仍最多 180 秒。「尽快完成」跳过额外场间休息。 |
| 免费一键随机选技 | 默认开启，可在 GUI 关闭；只用上游明确的 class/背景图识别，失败后走原有评分选卡，绝不回退点击任意按钮。关内技能仍按评分选择。 |
| 日活跃 240 分钟后休息 90 分钟 | 改为清楚标注的「活跃满/休息」，均可配置。保留上游跨天重置、休息后重新累计的语义；仅在实际回到大厅且任务未完成时休息，暂停不计时，计时和休息截止时间均持久化。 |
| 无头 UA 修正 | 合入，只替换 HeadlessChrome；保留真实平台及可读取的 UA metadata。CDP 会话保留到浏览器关闭，避免 detach 撤销覆盖。 |
| 显卡/插件/权限等指纹补丁 | 未启用。上游会将软件渲染硬编码为 NVIDIA/Direct3D，还会将用户禁用通知改成 default；这与真实环境可能矛盾。 |
| 通用统计 GIF 拦截 | 限定 hostname=`dotserver.douyucdn.cn`、path=`/fish3/1.gif`，返回透明 GIF；可关闭。业务请求不拦截、不改字段，继续接受 API 基准检查。 |
| 概率秒杀 + 概率漏回血捆绑 | 添加独立「温和伤害」选项：12% 击杀，否则当前血量的 55–90%。不改变用户已有伤害策略、独立回血、攻速和分系覆盖。未移植随机漏回血。 |
| 默认无限单场、超时/异常直接计场 | 保留本分支：GUI 实时单场时限、正常收尾、首轮攻击防零伤害、180 秒宽限与暂停、真实结算后计场。 |
| 宝箱误判结算修复 | 保留本分支已有更完整的大厅/战斗状态复核，不以进度宝箱作为结算。 |
| 登录成功确认 | 合入；登录时只在内存比较凭据变化，不记录 Cookie。确认过程写入 GUI 日志。已有凭据也会主动验证。 |
| GUI / 打包 | 保留紧凑布局、外部配置、API 基准、普通版与 Debug 双 EXE Release；新增左侧休息设置和随机选技开关。 |

## 配置兼容

旧 `config.json` 的伤害策略、倍率、分系覆盖、场数、时限和登录目录保持原值。
新配置默认 `daily_limit_min=240`、`rest_min=90`、`random_skills=true`、`block_stats=true`。
除休息/随机选技设置按下一次启动任务读取，原有实时设置继续按原规则应用。
`active_state.json` 记录活跃累计与休息截止时间，升级时与其他外部配置一同保留。

API 基准未自动扩充。若游戏实际请求出现新增接口/字段，仍暂停、恢复原生逻辑并生成报告，
不能因为合并上游就默许未知业务上报。
